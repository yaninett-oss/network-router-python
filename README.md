# network-router-python

Программный маршрутизатор и многоклиентская сеть на Python.

Практическая работа №2 по компьютерным сетям.

---

## Что это

Учебная модель компьютерной сети, состоящая из:

- **7 клиентов**;
- **3 логических подсетей**;
- **программного маршрутизатора**;
- **TCP- и UDP-соединений**;
- **приоритетных и обычных пользователей**;
- **таблицы маршрутизации**.

Все программы запускаются на одном компьютере (`127.0.0.1`), но подсети и IP-адреса — **логические**, и маршрутизатор работает с ними как с реальными.

```
  ▼    ▼    ▼      ▼    ▼    ▼          ▼
 C1   C2   C3     C4   C5   C6         C7
```

## Как запустить

### 1. Запустить маршрутизатор

В отдельном терминале:

```
python router.py
```

Должно появиться:

```
[ROUTER] TCP ожидает подключения: 127.0.0.1:5000
[ROUTER] UDP ожидает сообщения: 127.0.0.1:6000
```

### 2. Запустить TCP-клиентов

В отдельных терминалах:

```
python client_tcp.py Client1
python client_tcp.py Client2
python client_tcp.py Client3
python client_tcp.py Client7
```

### 3. Запустить UDP-клиентов

В отдельных терминалах:

```
python client_udp.py Client4
python client_udp.py Client5
python client_udp.py Client6
```

### 4. Отправлять сообщения

В консоли клиента формат:

```
получатель|приоритет|текст
```

Примеры:

```
Client4|HIGH|Привет!
Client2|NORMAL|Как дела?
Client5|HIGH|Срочное сообщение
```

### 5. Служебные команды

```
/list    — список подключённых клиентов
/stats   — статистика трафика
exit     — выход
```

## Что умеет маршрутизатор

- Регистрация клиентов по имени (`REGISTER|ClientN`)
- Разделение клиентов на логические подсети
- TCP- и UDP-подсети
- Маршрутизация между подсетями
- Преобразование TCP ↔ UDP на прикладном уровне
- Приоритеты HIGH / NORMAL
- Автоматический приоритет (пользователь HIGH → сообщение HIGH)
- Задержка обычного трафика (демонстрация приоритета)
- Статистика: TCP/UDP/HIGH/NORMAL/внутри/между подсетями
- Команды `/list` и `/`
- Логирование в файл `router.log`
- Цветной вывод в консоль
- Обработка отключённых и неизвестных клиентов

## Пример работы

Клиент `Client1` (TCP, NORMAL) отправляет:

```
Client5|HIGH|Привет из подсети 1!
```

Маршрутизатор выводит:

```
[ROUTER] ПОЛУЧЕНО СООБЩЕНИЕ
  Отправитель:        Client1 (192.168.1.10)
  Получатель:         Client5 (192.168.2.11)
  Подсеть отправителя: 192.168.1.0/24
  Подсеть получателя:  192.168.2.0/24
  Протокол отправителя: TCP
  Протокол получателя:  UDP
  Приоритет:           [HIGH]
  Сообщение:           Привет из подсети 1!
[ROUTER] Приоритетное сообщение.
[ROUTER] Выполняется межсетевой маршрут.
[ROUTER] Выполняется преобразование протокола.
```

Клиент `Client5` получает:

```
[HIGH] Client1 → Client5: Привет из подсети 1!
```
